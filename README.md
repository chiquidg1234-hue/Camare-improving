# LumaCam

Cámara para Android (Kotlin, CameraX, OpenGL ES, Jetpack Compose) pensada para el Honor X7c:
looks en tiempo real (Natural, Cálido, Cine, Vívido, Nocturno) en vista previa y video, y foto
multi-frame con alineación, reducción de ruido y el mismo look aplicado.

- **Instalar y probar:** ver [NOTAS.md](NOTAS.md).
- **Estado del trabajo:** ver [PROGRESO.md](PROGRESO.md).
- **Compilar:** `./gradlew assembleDebug` (necesita Android SDK; GitHub Actions lo hace solo).
- **Pruebas de la lógica sin SDK:** `./gradlew -p core test`.
